快速上手
  1. 先到「批量生成」用 Dry run 跑 30 张，系统会在本地生成演示图，不花一分钱，可以把画廊、筛选、提示词编辑、复现、导出全部走通。
  2. 确认配方稳定后，到「连接设置」粘贴 API key 并点「验证连接」。密钥只保存在服务进程内存里，不写任何文件；也可以改用环境变量 OPENAI_API_KEY。取消 Dry run 才会真正调用 API。
  3. 在画廊点开一张图，可直接改提示词、保存版本、一键复现、打分、加标签、标为精选。
  4. 精选资产可导出 ZIP 素材包，或一键同步到资产盘（D:/gdrive.photo/ai-assets，即 H: 对应的本地目录，会由 Google Drive 自动同步到云端）。

顺序

风格 1「复古胶片日记」是 active，风格 4「扁平几何图标」是 queued。第一套跑顺后到「风格配方」页把 4 切成 active 即可。

合规提醒

把成品发布到平台时，按平台要求勾选「含 AI 生成内容」。图片自带的 C2PA 来源元数据不要剥离；本系统会在「元数据完整性」里检查。不要生成在世艺术家风格、公众人物或真实人脸的写实形象。

关于网络与代理

本机需要通过代理访问 OpenAI API 时，在 config.json 里设置 api_proxy（例如 http://127.0.0.1:1080），服务重启后生效；也可以在「连接设置」页临时改代理，立即生效但重启后失效。api_base 用于兼容网关或中转端点。密钥不写入任何文件：优先用界面上的会话密钥，其次读环境变量 OPENAI_API_KEY。

关于资产盘

资产根目录是 D:/gdrive.photo/ai-assets：这是 H: 镜像盘对应的本地目录，写入后会由 Google Drive 自动同步。直接写这个本地目录比写 H: 虚拟盘稳定，也避免几千张小文件与同步客户端打架。若同步客户端没运行，写入仍然成功，只是云端稍后才会更新。
