快速上手
  1. 先到「批量生成」用 Dry run 跑 30 张，系统会在本地生成演示图，不花一分钱，可以把画廊、筛选、提示词编辑、复现、导出全部走通。
  2. 确认配方稳定后，到「连接设置」粘贴 API key。想明文落地就点「明文写入 config.json」（重启自动生效，但该文件是明文，务必确认 .gitignore 已排除）；更推荐勾选「记住到本机」用 DPAPI 加密保存。也可以直接设环境变量 OPENAI_API_KEY。取消 Dry run 才会真正调用 API。
  3. 在画廊点开一张图，可直接改提示词、保存版本、一键复现、打分、加标签、标为精选。
  4. 精选资产可导出 ZIP 素材包，或一键同步到资产盘（D:/gdrive.photo/ai-assets，即 H: 对应的本地目录，会由 Google Drive 自动同步到云端）。
  5. 做游戏角色时到「角色与游戏资产」：粘贴小说提取人物特征 → 核对并保存角色卡（生成带版本的锚点）→ 生成四视图设定图或精灵动画切图包。
角色一致性与动画切图

角色锚点是一段固定的、带版本号的英文人物设定，每次生成逐字放在提示词最前面。改外貌字段会自动重建锚点并升级版本；直接编辑锚点则保留手工文本。版本变了说明设定改过，旧图和新图不要混用。勾选参考图后，复现和逐视图生成会走 /images/edits 并设 input_fidelity=high，这是目前保持人物长相与画风最有效的手段。

多视角的 sheet 模式一次生成四格设定图再等分切图，只花 1 张的钱、内部一致性最好；separate 模式逐视图生成，4 张成本，但可逐张换姿势、配参考图。两种都把正面 / 3-4 侧 / 正侧面 / 背面四张独立 PNG 打进包里。

精灵动画不调用 API：从同一张基准 PNG 做确定性的位移、挤压、摆动、镜像变换，帧天然对齐。输出 sheet.png、逐帧 PNG、Aseprite/Phaser JSON、Godot 4 .tres、Unity 自动切片脚本、RPG Maker 行走图和可播放的 preview.html。四角自动抠背景；边缘残留就调容差，或改用 none 保留原背景。

顺序

风格 1「复古胶片日记」是 active，风格 4「扁平几何图标」是 queued。第一套跑顺后到「风格配方」页把 4 切成 active 即可。

合规提醒

把成品发布到平台时，按平台要求勾选「含 AI 生成内容」。图片自带的 C2PA 来源元数据不要剥离；本系统会在「元数据完整性」里检查。不要生成在世艺术家风格、公众人物或真实人脸的写实形象。

关于网络与代理

本机需要通过代理访问 OpenAI API 时，在 config.json 里设置 api_proxy（例如 http://127.0.0.1:1080），服务重启后生效；也可以在「连接设置」页临时改代理，立即生效但重启后失效。api_base 用于兼容网关或中转端点。密钥可以明文写在被 .gitignore 排除的 config.json 的 api_key 字段（不加密，注意风险），也可以加密保存到用户目录（重启自动生效）、只用会话内存密钥，或读环境变量 OPENAI_API_KEY。生效优先级：会话内存 > DPAPI 用户目录 > config.json 明文 > 环境变量。不要把密钥写进会被提交的 config.example.json。

关于资产盘

资产根目录是 D:/gdrive.photo/ai-assets：这是 H: 镜像盘对应的本地目录，写入后会由 Google Drive 自动同步。直接写这个本地目录比写 H: 虚拟盘稳定，也避免几千张小文件与同步客户端打架。若同步客户端没运行，写入仍然成功，只是云端稍后才会更新。
